# Results of an example simulation

Results of an example simulation study comparing the power of logrank
max-combo and modelstly weighted logrank test in differnt scenarios with
delayed onset of treatment effect.

## Usage

``` r
combination_tests_delayed
```

## Format

a `tibble` as returned by
[`SimDesign::runSimulation`](http://philchalmers.github.io/SimDesign/reference/runSimulation.md).
